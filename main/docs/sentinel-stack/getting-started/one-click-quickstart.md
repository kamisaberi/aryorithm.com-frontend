# One-Click Quickstart

> **Status:** Draft — placeholder content. Final technical prose is forthcoming.


One-command execution: sudo ./install.sh.

## Run

Clone, chmod, install — then watch six tiers compile in order.

## Time

Minutes on modern hardware, longer on first-time toolchain installs.

```bash
$ git clone https://github.com/kamisaberi/sentinel-stack.git
$ cd sentinel-stack && chmod +x install.sh scripts/*.sh
$ sudo ./install.sh
```
