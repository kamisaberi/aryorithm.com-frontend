# Overview

> **Status:** Draft — placeholder content. Final technical prose is forthcoming.


Capabilities and design principles of the xInfer Essential runtime.

## What it is

libxinfer.so is a native C++20 inference engine: one model graph executes across 15 heterogeneous backends through memory-mapped DMA buffers.

## What it is not

Not a training framework, not a Python package, not a cloud service. Training happens elsewhere; xInfer executes.
