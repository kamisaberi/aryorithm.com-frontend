# System Requirements

> **Status:** Draft — placeholder content. Final technical prose is forthcoming.


OS, compiler, and hardware prerequisites.

## Operating systems

Ubuntu 22.04/24.04 LTS, Debian 12, RHEL 9, Yocto Kirkstone+. x86_64 and AArch64.

## Compilers

GCC 12+ or Clang 16+, CMake 3.20+, Ninja recommended. C++20 standard library required.

## Hardware

Any 64-bit CPU; optional accelerators per silicon-backends/. 8 GB RAM suggested for int8 calibration.
